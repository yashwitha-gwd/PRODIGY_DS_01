# Population Distribution Visualization

## Overview
This project focuses on visualizing population distribution using the Titanic dataset. The goal was to understand how continuous and categorical data can be represented using different visualization techniques.

## Dataset Used
Titanic Dataset

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Workflow

### 1. Data Collection
Loaded the Titanic dataset containing passenger details like age and gender.

### 2. Data Cleaning
Handled missing values in the Age column to make the dataset ready for analysis.

### 3. Data Visualization
Created:
- Histogram to visualize age distribution
- Bar chart to compare gender distribution

### 4. Insights
- Most passengers were between 20–35 years old
- Male passengers were more than female passengers
- Histograms helped understand continuous data distribution clearly

## Outcome
Learned how to clean data and create meaningful visualizations using Python libraries.
